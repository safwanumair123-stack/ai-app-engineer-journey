## Day 72 — Usability improvements and test fixes

Day 72 focused on improving the usability of the Enquiry Tracker and resolving two automated test failures.

### Usability improvements

- Made the Log out and Admin dashboard links clearly visible in the header.
- Improved the dashboard layout by showing the most important information first.
- Moved detailed dashboard reports into a collapsible section.
- Improved the enquiry details page by adding a clear enquiry summary.
- Moved the full enquiry edit form into a collapsible section.
- Made the enquiry list easier to scan by showing key details first.
- Moved less urgent enquiry details into a collapsible “More details” section.

### Test fixes

- Updated the Log In page so it displays the success message after a new account is created.
- Updated admin access protection so a logged-in regular user sees an access-denied page instead of being redirected.
- Confirmed that all 10 automated tests pass.

### Result

The Enquiry Tracker is now easier to understand and use. Users can quickly see which enquiries need attention, create new enquiries, review enquiries, add notes, and manage enquiry status.
