# Day 72 — Learning Notes

## What I learned

- Good design is not only about making an application work. It is also about making it easy for a real user to understand and use.
- Colour contrast is important. Dark blue text on a dark blue background was difficult to see.
- A dashboard should show the most important information first.
- Too much information on one page can make an application feel confusing.
- Collapsible sections can hide detailed information without removing useful features.
- An enquiry list should help a user quickly identify which enquiry needs attention.
- Automated tests can reveal problems that may not be obvious during manual testing.
- A success message should be displayed clearly after an important action such as creating an account.
- Access control should give users a clear explanation when they do not have permission to view a page.

## Improvements I made

- Fixed invisible Log out and Admin dashboard links.
- Made the dashboard easier to scan.
- Made the enquiry details page clearer.
- Made the enquiry list easier to scan.
- Fixed the missing account-creation success message.
- Added a clear access-denied page for regular users trying to access the Admin dashboard.

## Test result

All 10 automated tests passed.

## What I would improve next

- Show high-priority open enquiries more clearly.
- Improve the visual design of buttons and status labels.
- Add clearer feedback after important actions.
