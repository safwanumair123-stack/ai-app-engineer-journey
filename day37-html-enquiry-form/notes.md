# Day 37 — Create the First Enquiry Tracker Interface

## What I learned

- How to create a basic HTML page.
- How to structure a form.
- How to use labels and input fields.
- How to create dropdown menus.
- How to add buttons.
- How to test a web page through a local server.

## What I built

I created the first HTML interface for the Enquiry Tracker.

The page includes a header, a form to create a new enquiry, and a section for the enquiry list.

The form includes fields for customer name, enquiry type, priority, enquiry details, and next action.

## Current limitation

The form does not save data yet.

The next step will be to connect the interface to Python logic so the enquiry can be saved and displayed.

## Testing

I tested five scenarios:

1. Opened the page through the local server.
2. Entered a customer name.
3. Selected an enquiry type.
4. Selected a priority.
5. Used the Clear form button.

All five tests passed.

## Why this matters

A simple interface makes an application easier for a non-technical business owner to use. It also helps turn a command-line workflow into a practical business tool.
