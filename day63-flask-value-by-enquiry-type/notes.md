# Day 63 — Add Enquiry Value by Enquiry Type

## What I learned

- How to group numeric values by enquiry type.
- How to calculate a total value for each enquiry type.
- How to display value-based service insights.
- How to test grouped calculated values.
- How to connect dashboard metrics to business decisions.

## What I built

I added enquiry value by enquiry type to the Enquiry Tracker dashboard.

The dashboard now calculates the total estimated value for each enquiry type: General enquiry, Quotation, Support, and Partnership. This helps a small business owner see which types of enquiries bring the most potential business value.

## New skill

I learned how to calculate grouped business metrics by enquiry type.

## Testing

I tested five scenarios:

1. Created enquiries with different enquiry types and estimated values.
2. Checked that the value for each enquiry type was correct.
3. Changed an enquiry type and checked that the value moved to the correct type.
4. Deleted an enquiry and checked that its value was removed from the correct type.
5. Deleted all enquiries and checked that all enquiry type values returned to zero.

All five tests passed.
