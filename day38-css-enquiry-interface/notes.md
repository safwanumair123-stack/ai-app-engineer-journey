# Day 38 — Style the Enquiry Tracker Interface

## What I learned

- How to link a CSS file to an HTML page.
- How to style headings, text, forms, and buttons.
- How to use spacing and colours for readability.
- How to make a simple responsive layout.
- How to test a web page at mobile width using Chrome DevTools.

## What I built

I added a styles.css file to the Enquiry Tracker interface.

The CSS improved the appearance of the header, form fields, buttons, sections, and footer. It also made the layout more readable on smaller screens.

## Improvements made

- Added a dark blue header with white text.
- Added a light grey page background.
- Created card-style sections for the form and enquiry list.
- Made form fields full width and easier to read.
- Styled the Create enquiry and Clear form buttons.
- Added a mobile-friendly layout for screens up to 600 pixels wide.

## Testing

I tested five scenarios:

1. Opened the page and confirmed the CSS styling appeared.
2. Checked that the form fields were styled correctly.
3. Checked that the buttons were styled correctly.
4. Tested the page at 375-pixel width using Chrome DevTools.
5. Used the Clear form button and confirmed it still worked.

All five tests passed.

## Why this matters

CSS makes an interface easier to read and use. A clear, mobile-friendly interface is important for small-business users who may access the tool from a phone, tablet, or computer.
