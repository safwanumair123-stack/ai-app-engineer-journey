## Day 73 — Practical dashboard

### What I learned

- A useful dashboard should help a user decide what to do next.
- Showing overdue follow-ups and high-priority open enquiries makes the tracker more practical.
- Sorting action-needed enquiries by follow-up date helps users focus on the most urgent work.
- A dashboard should highlight important actions rather than only displaying totals.
- CSS is important because it controls the visual structure and usability of the application.

### Improvement I made

Added an “Enquiries that need action” section to the dashboard.
