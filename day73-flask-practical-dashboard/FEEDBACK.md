# Enquiry Tracker — Feedback and Improvements

## Day 72 usability improvements

### Issue 1: Invisible logout and admin links

**Problem identified**

After logging in, the Log out and Admin dashboard links were difficult to see because the link text was dark blue against a dark blue header background.

**Improvement made**

Changed the header link colour to white and added a hover colour. The Log out and Admin dashboard links are now clearly visible.

**Result**

Users can now easily see how to log out and, for Admin users, access the Admin dashboard.

### Issue 2: Dashboard was too detailed

**Problem identified**

The dashboard showed many detailed reports at once. This made it harder to quickly understand which enquiries need attention.

**Improvement made**

Moved the most important information to the top: overdue follow-ups, new enquiries, in-progress enquiries, total estimated value, and the top three highest-value enquiries.

Moved detailed reports into a collapsible section called “Detailed dashboard reports.”

**Result**

The dashboard is easier to scan and focuses attention on the most useful information.

### Issue 3: Enquiry details page was too long

**Problem identified**

The enquiry details page showed the full edit form immediately. This made it harder to quickly review the enquiry and see the notes and actions.

**Improvement made**

Added a clear enquiry summary at the top.

Moved the full edit form into a collapsible section called “Edit enquiry details.”

Kept notes and enquiry actions clearly separated.

**Result**

Users can quickly review an enquiry, add a note, and choose the correct action.

### Issue 4: Enquiry list showed too much information

**Problem identified**

Each enquiry card showed customer email, phone number, assigned person, source, and created date. This made the list harder to scan.

**Improvement made**

Kept the most important details visible: reference number, customer, enquiry type, priority, status, estimated value, follow-up date, and action link.

Moved less urgent details into a collapsible “More details” section.

**Result**

The enquiry list is easier to scan and helps users identify which enquiry needs attention.

## Overall result

The Enquiry Tracker is now clearer, more professional, and easier to use. The main workflow is easier to follow:

1. Check what needs attention.
2. Create a new enquiry if needed.
3. Search, filter, and review enquiries.
4. Open an enquiry, add notes, update details, and manage its status.
