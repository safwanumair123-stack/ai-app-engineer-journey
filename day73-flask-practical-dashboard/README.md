## Day 73 — Practical dashboard

Day 73 focused on making the dashboard more practical for daily use.

### Improvement made

Added an “Enquiries that need action” section to the dashboard.

This section shows open enquiries that have either:

- An overdue follow-up date.
- High priority.

Each enquiry card shows the customer, reference number, priority, status, follow-up date, next action, and a link to open the enquiry.

### Result

The dashboard now helps users quickly identify which enquiries need attention first.
