# Day 50 — Add Enquiry Source and Source Filtering

## What I learned

- How to add a controlled dropdown field to an enquiry.
- How to validate a selected enquiry source.
- How to edit an enquiry source.
- How to filter enquiries by source.
- How to include the source in a CSV export.

## What I built

I added an enquiry source feature to the Enquiry Tracker.

The user can select where an enquiry came from: Website, WhatsApp, Email, Referral, or Phone call. The user can also filter the enquiry list by source. The dashboard shows how many enquiries came from each source, and the CSV export includes the enquiry source.

## New skill

I learned how to track the origin of a business enquiry and use that information for filtering and reporting.

## Testing

I tested five scenarios:

1. Created three enquiries with different enquiry sources.
2. Checked the dashboard source counts.
3. Filtered the enquiry list by one source.
4. Edited the enquiry source on one enquiry.
5. Downloaded the CSV file and confirmed the enquiry source appeared in the correct column.

All five tests passed.
