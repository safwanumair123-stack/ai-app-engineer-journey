# Day 4 — Inspecting API Requests

## Completed
- Opened Chrome Developer Tools and the Network panel.
- Sent a practice request from the form.
- Observed a 204 preflight entry and a 201 fetch entry.
- Inspected the outgoing JSON in the Payload tab.
- Inspected the returned JSON in the Response tab.
- Compared the payload with the response: the response included id: 101.

## Key learning
Payload is the data my app sends.
Response is the data my app receives.
The Network panel lets me inspect the exchange directly,
rather than relying only on the page's success message.
