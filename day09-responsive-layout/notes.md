## Key learning
Responsive design should begin by testing the current layout.

A viewport meta tag helps mobile browsers use the device width.
Media queries can apply CSS only when a condition is met, such as
a narrow screen width.

If the existing layout already works, adding extra CSS may create
unnecessary complexity.
