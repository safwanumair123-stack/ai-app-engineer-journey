# Day 61 — Add Enquiry Value by Source

## What I learned

- How to group numeric values by an enquiry source.
- How to calculate a total value for each source.
- How to display value-based marketing metrics.
- How to test grouped calculated values.
- How to connect dashboard metrics to business decisions.

## What I built

I added enquiry value by source to the Enquiry Tracker dashboard.

The dashboard now calculates the total estimated value for each enquiry source: Website, WhatsApp, Email, Referral, and Phone call. This helps a small business owner see which channels bring the most potential business value.

## New skill

I learned how to calculate grouped business metrics by enquiry source.

## Testing

I tested five scenarios:

1. Created enquiries from different enquiry sources.
2. Checked that the value for each source was correct.
3. Changed an enquiry source and checked that the value moved to the correct source.
4. Deleted an enquiry and checked that its value was removed from the correct source.
5. Deleted all enquiries and checked that all source values returned to zero.

All five tests passed.
