# Day 49 — Add Enquiry Assignment

## What I learned

- How to add an assigned-to field to an enquiry.
- How to assign an enquiry when it is created.
- How to edit an assignment later.
- How to filter enquiries by assigned person.
- How to include the assignment in a CSV export.

## What I built

I added an enquiry assignment feature to the Enquiry Tracker.

The user can enter a team member’s name when creating an enquiry. The user can also edit the assignment later from the individual enquiry page. The enquiry list can be filtered by assigned person, and the CSV export includes the assigned person’s name.

## New skill

I learned how to add ownership or responsibility to a business record.

## Testing

I tested five scenarios:

1. Created three enquiries and assigned them to different team members.
2. Filtered the enquiry list by one assigned person.
3. Edited the assigned person on one enquiry.
4. Confirmed that the updated assignment appeared in the enquiry list.
5. Downloaded the CSV file and confirmed that the assigned person appeared in the correct column.

All five tests passed.
